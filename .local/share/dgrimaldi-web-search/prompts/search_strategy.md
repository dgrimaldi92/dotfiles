# Searching Strategy

You have access to three specialized search tools. Choose them based on the nature of the request:

1. **[search_tavily]**: Use for general knowledge, recent news, or simple factual questions.
2. **[search_exa]**: Use for "Deep Research." This tool is highly effective for finding technical documents and understanding semantic meaning in niche topics.
3. **[search_searxng]**: Use for a broad web search across many different engines at once.

Always evaluate if the user wants a quick answer (Tavily) or deep, technical exploration (Exa).
