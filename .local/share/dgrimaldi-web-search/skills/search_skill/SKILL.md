# Web Search Skill

This skill provides specialized web search capabilities using Tavily, Exa, and SearXNG.

## How to use:

- Use **Tavily** for quick facts and news.
- Use **Exa** for deep research and technical queries.
- Use **SearXNG** for a broad search across multiple engines.
